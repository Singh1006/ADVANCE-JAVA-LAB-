# Student Registration Form Using Java Swing

A desktop-based Student Registration Form developed using Java Swing. The application provides a graphical user interface to enter and submit student details.

## Features

- Student name input
- Roll number entry
- Gender selection
- Branch selection
- Terms and conditions checkbox
- Submit button
- Reset button
- Graphical user interface using Java Swing

## Technologies Used

- Java
- Java Swing
- AWT
- JDK
- Visual Studio Code

## Prerequisites

- JDK installed
- Visual Studio Code or another Java IDE

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/anjuyadav21122006-crypto/StudentRegistration-Java-Swing.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open the Java source file containing the main method.
4. Compile the program:

   ```bash
   javac StudentRegistration.java
   ```

5. Run the application:

   ```bash
   java StudentRegistration
   ```

The Student Registration Form window will open.

## Learning Objectives

- Understand Java Swing components.
- Learn to create graphical user interfaces.
- Handle button click events using `ActionListener`.
- Practice form input and basic event handling.
