# TCP Client–Server Application in Java

A Java networking project that demonstrates communication between a client and a server using TCP sockets.

## Features

- Client–server communication
- TCP socket programming
- Sending requests from the client to the server
- Server-side request processing
- Java networking fundamentals

## Technologies Used

- Java
- TCP/IP networking
- Java Socket and ServerSocket
- Visual Studio Code
- JDK

## Prerequisites

- JDK installed
- Visual Studio Code or another Java IDE

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/anjuyadav21122006-crypto/TCP-Client-Server.git
   ```

2. Open the project folder in Visual Studio Code.
3. Compile the Java source files:

   ```bash
   javac *.java
   ```

4. Start the server by running the appropriate server class:

   ```bash
   java Server
   ```

5. Open a second terminal and start the client:

   ```bash
   java Client
   ```

6. Observe the communication between the client and server in the terminals.

**Note:** If the project uses RMI or additional interfaces, follow the class dependencies and startup requirements in the source code.

## Learning Objectives

- Understand TCP client–server architecture.
- Learn Java socket programming.
- Practice sending and receiving data over a network.
- Understand how a server handles client requests.
